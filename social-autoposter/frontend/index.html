Hướng dẫn 3 bước đăng nhập:
  • Nhấn nút "Mở trình duyệt Chromium để đăng nhập" bên dưới.
  • Cửa sổ trình duyệt tự động mở trang Facebook. Bạn chỉ cần nhập tài khoản, mật khẩu và mã xác thực 2FA.
  • Đăng nhập thành công vào Bảng tin, hệ thống sẽ tự động trích xuất phiên làm việc an toàn và đóng trình duyệt.
Cách 2: Nhập Cookie từ Chrome của bạn
Dành cho tài khoản phụ / nuôi nick
Hướng dẫn lấy Cookie trong 15 giây (F12): Chuẩn F12 Chrome
1 Mở tab Chrome mới ➔ Đăng nhập vào facebook.com.
2 Nhấn phím F12 (hoặc chuột phải chọn Kiểm tra / Inspect).
3 Chọn tab Application (Ứng dụng) ➔ Ở cột bên trái, mở mục Cookies ➔ Chọn https://www.facebook.com.
4 Tìm dòng tên c_user copy ô Value dán vào ô UID; tìm dòng xs copy ô Value dán vào ô Token bên dưới.
Mẹo nhanh 1-Click: Có thể cài extension J2Team Cookies hoặc Get Cookie for Fplus để sao chép toàn bộ chuỗi cookie và dán vào ô bên dưới.

Kết nối Facebook Fanpage

Graph API v19.0

Cấp quyền xuất bản tự động lên trang Fanpage doanh nghiệp

Hướng dẫn 4 bước lấy Page Access Token: Mở công cụ Meta
1 Truy cập Meta Graph API Explorer và đăng nhập tài khoản Facebook quản trị Fanpage.
2 Tại mục Meta App, chọn Ứng dụng của bạn. Tại mục User or Page, chọn đúng Fanpage bạn muốn kết nối.
3 Nhấn Add a Permission và tick chọn 3 quyền cần thiết: pages_show_list, pages_read_engagement, pages_manage_posts.
4 Bấm nút Generate Access Token ➔ Cấp quyền trên cửa sổ Facebook ➔ Sao chép chuỗi mã Token bắt đầu bằng EAAB... dán vào form bên dưới.
Mẹo Token vĩnh viễn: Vào công cụ Access Token Tool gia hạn sang Token Page dài hạn (Never Expire) để không phải cấp lại sau 60 ngày.

ZALO

Kết nối tài khoản Zalo

Cấu hình Zalo OpenAPI cho Doanh nghiệp hoặc Quét mã QR cho Cá nhân

Hướng dẫn 4 bước cấu hình Zalo OpenAPI: Mở developers.zalo.me
1 Truy cập developers.zalo.me và đăng nhập tài khoản Zalo quản trị trang OA.
2 Chọn Ứng dụng của bạn (hoặc nhấn Tạo ứng dụng mới) ➔ Vào mục Liên kết Official Account để chọn OA Doanh nghiệp.
3 Mở menu Công cụ ➔ Tạo Access Token ➔ Chọn OA và tích chọn quyền: oa.article.manage (Đăng bài nhật ký) và oa.message.manage.
4 Bấm Tạo Access Token ➔ Sao chép mã Token cùng với OA ID và Secret Key dán vào form bên dưới.
Hướng dẫn quét mã QR Zalo trong 3 bước:
1 Mở ứng dụng Zalo trên điện thoại di động của bạn.
2 Chạm vào biểu tượng Quét mã QR (ở góc trên bên phải thanh tìm kiếm của app Zalo).
3 Hướng camera điện thoại vào mã QR bên dưới ➔ Bấm "Đăng nhập trên máy tính" để hoàn tất.
Bảo mật tuyệt đối: Phiên làm việc được mã hóa cục bộ trên máy chủ, không yêu cầu và không lưu mật khẩu.
Mã QR có hiệu lực trong: 120s Đang lắng nghe tín hiệu quét từ thiết bị...

Kết nối Meta Threads & X (Twitter)

Cấu hình API Keys chính thức từ cổng lập trình viên quốc tế

Hướng dẫn lấy Threads API Token: Meta for Developers
1 Đăng nhập developers.facebook.com ➔ Tạo ứng dụng mới hoặc chọn App hiện có.
2 Thêm sản phẩm Threads API ➔ Cấp quyền threads_basic và threads_content_publish.
3 Tại mục Threads Tester, thêm tài khoản Threads của bạn và tạo mã Long-lived Access Token (hạn 60 ngày).
4 Sao chép Threads User ID và Access Token dán vào form bên dưới.
Hướng dẫn lấy X (Twitter) API Keys: developer.x.com
1 Truy cập developer.x.com ➔ Đăng ký tài khoản Developer Free/Basic.
2 Tại mục Project & Apps, vào User authentication settings ➔ Bật quyền Read and Write.
3 Tạo và sao chép: API Key, API Secret Key và Bearer Token (hoặc Access Token & Secret).
4 Dán các mã khóa vào các ô tương ứng bên dưới và nhấn Lưu cấu hình.

Cấu hình & Tối ưu hóa kênh

Thiết lập giãn cách an toàn chống checkpoint và IP proxy riêng

Khuyến nghị vận hành an toàn từ chuyên gia:
Fanpage xác thực: Giãn cách 1 - 2 phút là hoàn toàn an toàn do dùng Meta Graph API chính thức.
Facebook Groups: Bắt buộc giãn cách 3 - 5 phút để tránh thuật toán phát hiện hành vi spam của Facebook.
Nick cá nhân / Zalo: Nên giãn cách 5 - 8 phút để nuôi tài khoản bền vững và tránh bị giới hạn tính năng.
Hướng dẫn: Nhập định dạng http://user:pass@host:port. Khuyên dùng Proxy dân cư tĩnh nếu chạy nhiều tài khoản để tránh bị khóa nick do trùng IP.
